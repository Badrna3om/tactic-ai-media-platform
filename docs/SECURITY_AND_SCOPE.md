# Security & Disclosure Boundaries

This repository contains **descriptive documentation only**. The production platform is proprietary.

## Included
- High-level system architecture and business-facing capabilities.
- Sanitized operational aggregates recorded on a stated date.
- Links to already public brand output.
- Engineering problems and design patterns, described without implementation secrets.

## Intentionally excluded
- Production workflow JSON, scripts, database dumps or configuration files.
- API keys, tokens, OAuth credentials, signing secrets, service-role keys.
- Private webhook URLs, internal domains, IP addresses or infrastructure identifiers.
- Model system prompts, proprietary routing/selection logic or exact vendor contracts.
- Customer/private user data, Telegram chat IDs or unpublished editorial materials.
- Raw video files or images that might have separate third-party rights.

## Responsible interpretation

- **Rendered** does not equal **published**.
- **Media indexed** does not equal **video distributed**.
- **Telegram delivery** does not imply automatic Snapchat publication.
- Public social links evidence selected examples, not full account analytics.

## Security review of these documents

Documents were drafted from **aggregated counts, confirmed public-post URLs and abstract capabilities** only. No runtime access is given to visitors. All future additions should be reviewed for embedded credentials, personal details, proprietary prompts, paid-content licensing and internal endpoint exposure before commit.

For security concerns, contact the repository owner through GitHub. Do not open an issue containing credentials or private logs.
